# ADR-060: Spelling knowledge model

Status: Accepted

Date: 2026-10-05

## Context

Spelling needs structured topics, rules, clauses, and examples. An article body would hide the difference between a rule, an exception, and a common mistake.

## Decision

The `spelling` module stores topics, rules, clauses, and examples. Quoted examples and common mistakes require a shared citation. A contrast that shows another form must name the context. Publication requires a clause and a rule-level citation.

## Consequences

Public spelling pages read published snapshots. There is no spell-checker engine in this stage.
