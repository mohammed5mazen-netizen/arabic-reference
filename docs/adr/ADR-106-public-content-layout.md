# ADR-106: Public content layout

Status: Accepted

Date: 2026-10-09

## Context

A rule, an article, and a tool do not want the same density as an admin table.

## Decision

Public reading uses a narrow measure and a page header (eyebrow, title, summary). Senses stay separate. Sources use `SourceCard`. Related links render only when the record supplies a target. Admin tables may scroll; public knowledge prefers stacked blocks.

## Consequences

Long quotations stay inside the reading width. A wide comparison stays on the tool page that already stacks on small screens.
